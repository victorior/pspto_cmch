- (direction) Usuario elige Factura o Boleta de Honorarios al crear OC; si Boleta asigna % retención; si Factura elige afecta IVA o exenta; sistema aplica formato e impuesto
- (direction) Al crear OC no debe exigirse imputación obligatoria de actividad/presupuesto
- (note) Modo express: requisitos claros en chat; gaps a open_questions
- (capability) CAP-1: Al crear OC el usuario elige tipo de documento (Factura | Boleta de Honorarios) y el sistema fija formato e impuesto según la rama elegida
- (capability) CAP-2: Si elige Boleta de Honorarios, puede asignar el porcentaje de retención aplicado al cálculo
- (capability) CAP-3: Si elige Factura, indica si afecta al IVA o es exenta; el sistema aplica IVA 19% o cero según esa elección
- (capability) CAP-4: Al crear OC el usuario puede guardar sin imputar actividad/línea de presupuesto
- (decision) Perfiles tributarios resultantes: iva (19%), exento (0%), retencion (% usuario); reutilizar semántica de oc_tax_profile existente
- (decision) La elección del usuario manda sobre la inferencia por nombre/código de producto al crear la OC
- (constraint) Debe aplicarse en el flujo de creación de OC (UI + validación servidor); el perfil elegido debe persistir con la OC para impresión y recálculo
- (constraint) Fórmulas de totales no cambian: IVA=neto*19%; retención=subtotal*%/100; total boleta=subtotal-retención
- (constraint) Actividad sigue siendo opcionalmente imputable; no se elimina Buscar Actividades
- (constraint) Multi-tenant y secretos fuera de DocumentRoot; sin reset de datos en producción
- (assumption) El mismo comportamiento aplica al editar una OC existente (consistencia con create)
- (assumption) IVA afecta usa 19% fijo ya implementado; no se pide % IVA al usuario
- (assumption) Sin actividad, la OC no consume presupuesto hasta que se imputen líneas
- (question) ¿Cuál es el % de retención por defecto al elegir Boleta si el usuario no ingresa valor? (hoy el legado usa 12.25 en algunos paths)
- (question) ¿Se permite cambiar el tipo de documento después de emitida/aprobada la OC, o solo en borrador/creación?
- (question) ¿OC sin actividad puede avanzar a estados posteriores (emitida/enviada) o queda restringida hasta imputar?
